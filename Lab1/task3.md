Part 4. Count the Steps
Given:
FOR i = 1 to 5
    PRINT i


1. How many times does this loop run?

The loop runs from 1 to 5.

Total iterations = 5.

Answer: 5 times.

2. If the loop ran from 1 to n and n = 20, how many times will it run?

Total iterations = n.

Since n = 20:

Answer: 20 times.

Given:
FOR i = 1 to 5
    FOR j = 1 to 5
        PRINT i, j


3. How many times does the inner PRINT run in total?
- Outer loop runs 5 times.
- Inner loop runs 5 times for every outer iteration.
\[
5 \times 5 = 25
\]

Answer: 25 times.

4. If both loops ran from 1 to n and n = 10, how many times will PRINT run?
\[
n \times n = 10 \times 10 = 100
\]

Answer: 100 times.
